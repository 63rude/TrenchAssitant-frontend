🔒 Limitations

Be aware that this is a test version of Trench Assistant. The features shown today are only a small preview of what the final tool will offer.

  • 🔁 Demo mode: Each wallet can be analyzed up to 3 times, and only the latest 50 transactions are fetched. This limitation helps us manage API costs and ensures fair access for all users.
  • 📊 Partial data: We currently display just a fraction of the final statistics. In the full version, each user will have a tailored and deeper statistical model.
  • ⛔ Network scope: For now, the bot only supports Solana wallets. Ethereum and other chains will be added in future phases.
  • ⚠️ Wallet limitations: Currently, wallets trading primarily on Pump.fun or dealing with extremely low-cap tokens may not be fully supported due to limitations in the Raydium API we use in this demo version.
  • 🧪 Early version: Features may be experimental or simplified. Final output and accuracy will improve continuously.
  • 📉 No financial advice: This tool is meant for informational and educational purposes only. Always do your own research (DYOR).

If analysis doesn’t return results, try a different wallet address — ideally one that has interacted with a broader range of tokens beyond very low-cap coins. Support for these is improving — reach out for early access to the upgraded version.
