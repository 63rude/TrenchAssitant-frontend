🔒 Limitations

This is an archived project. Analysis requires a locally running backend and your own API credentials.

  • 🔁 One run per wallet: The backend records analyzed wallets locally and collects up to 50 valid transfers per session.
  • 📊 Estimated results: The report is based on transfers and historical prices, not a full reconstruction of every trade.
  • ⛔ Network scope: The backend supports Solana wallets only.
  • ⚠️ External data: SolanaFM, Raydium, and Birdeye availability and response formats may have changed since this project was active.
  • 🧪 Project status: The original plans shown elsewhere on this site are historical, not an active product roadmap.
  • 📉 No financial advice: This tool is meant for informational and educational purposes only. Always do your own research (DYOR).

If an analysis returns no results, check the local backend logs and whether the wallet has supported transfer and price data.
