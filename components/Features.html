Core Features

The wallet analysis prototype was built; the larger terminal and other modules were part of the original concept.

🧠

Wallet Analysis Prototype

The prototype calculated wallet-level statistics. A larger terminal was planned with:

  • -Multivariate statistical analysis (up to 8 variables)
  • -Input filters: trade count, outlier exclusion, weekends skip
  • -Technical + on-chain data (indicators, volume, token traits)
  • -Analyze your own or any wallet (with token verification)
  • -Unlimited usage for eligible token holders

These extra controls and token access rules remained part of the concept.

📊

Token Smartness (Planned)

A planned module for studying holder behavior and social engagement signals:

  • -Detect profitable holders & smart money activity
  • -Filter social metrics for meaningful engagement
  • -Evaluate token traction based on organic vs. artificial signals

This module was part of the original concept and was not implemented here.

📈

Personal Risk Engine (Planned)

The original plan also included position sizing based on a trader's history:

  • -Position sizing based on the Kelly Criterion
  • -Calibration using each trader’s historical performance
  • -Available to users with significant trading history

This module was planned but was not implemented in the prototype.
